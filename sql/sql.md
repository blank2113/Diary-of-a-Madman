# 🗄️ **Язык SQL: Определение, Архитектура и Декларативность**

**SQL (Structured Query Language — Язык структурированных запросов)** — это стандартизированный декларативный язык, который используется для создания, модификации и управления данными в реляционных базах данных (таких как PostgreSQL, MySQL, SQLite, MS SQL, Oracle).

В отличие от традиционных языков программирования (JavaScript, TypeScript, Go), SQL спроектирован специально для работы с массивами данных, представленными в виде связанных между собой таблиц.

---

## 1. Главная фишка: Декларативный подход

SQL является **декларативным** языком. Это фундаментальное отличие от **императивных** языков (вроде JavaScript или Python).

* **Императивный подход (Как сделать):** Вы пишете пошаговый алгоритм. Например: *«Создай массив, запусти цикл `for`, внутри цикла проверь условие `if`, если оно верно — запушь элемент в новый массив»*.

* **Декларативный подход (Что получить):** Вы просто описываете критерии финального результата, который вам нужен. Например: *«Дай мне имена пользователей, у которых баланс больше 5000»*. 

Как именно база данных будет искать эти строки на жестком диске (пойдет ли она по индексу или будет перебирать файлы целиком), решает внутренний компонент СУБД — **Планировщик (Query Planner)**.

---

## 2. Как SQL видит данные: Реляционная модель

В основе работы SQL лежит **реляционная модель** (от английского *relation* — отношение/связь). Данные в такой модели организуются в виде двумерных таблиц.

* **Таблица (Отношение):** Сущность реального мира (например, `users` или `orders`).

* **Строка (Кортеж / Запись):** Конкретный экземпляр сущности (например, пользователь Алексей с ID 42).

* **Колонка (Атрибут / Поле):** Определенное свойство сущности, имеющее строгий тип данных (например, `email` в виде строки или `age` в виде числа).

Все таблицы внутри базы данных могут быть связаны между собой с помощью **Первичных (Primary Key)** и **Внешних ключей (Foreign Key)**.

---

## 3. Четыре кита SQL: Категории команд

Чтобы не путать команды, управляющие структурой таблиц, с командами, которые изменяют данные внутри этих таблиц, весь язык SQL разбит на 4 основные подмножества:


### 1. DDL (Data Definition Language — Язык определения данных)
Отвечает за архитектуру и структуру. Эти команды создают, изменяют или удаляют таблицы, схемы и индексы.
* `CREATE TABLE` — создать новую таблицу.
* `ALTER TABLE` — изменить структуру (например, добавить новую колонку).
* `DROP TABLE` — полностью удалить таблицу и все данные из неё.

### 2. DML (Data Manipulation Language — Язык манипулирования данными)
Самый используемый слой. Отвечает за работу с непосредственными записями внутри таблиц. Именно с этим слоем чаще всего взаимодействуют ORM-системы (например, Prisma в NestJS).
* `SELECT` — прочитать (выбрать) данные.
* `INSERT` — добавить новые строки.
* `UPDATE` — обновить существующие записи.
* `DELETE` — удалить строки.

### 3. DCL (Data Control Language — Язык управления данными)
Используется системными администраторами и DevOps для управления безопасностью и ролями пользователей СУБД.
* `GRANT` — выдать пользователю права на определенные операции (например, разрешить только `SELECT` из таблицы логов).
* `REVOKE` — отозвать выданные ранее права.

### 4. TCL (Transaction Control Language — Язык управления транзакциями)
Позволяет объединять несколько DML-команд в атомарные блоки для соблюдения принципов ACID (чтобы операции выполнялись по принципу «всё или ничего»).
* `BEGIN` (или `START TRANSACTION`) — открыть транзакцию.
* `COMMIT` — сохранить все изменения, сделанные внутри транзакции, на диск.
* `ROLLBACK` — отменить все изменения и вернуть базу в исходное состояние, если что-то пошло не так.

---

### Шпаргалка: Как выглядит простейший жизненный цикл данных в SQL

```sql
-- 1. Создаем структуру (DDL)
CREATE TABLE developers (
    id SERIAL PRIMARY KEY,
    name VARCHAR(100) NOT NULL,
    tech_stack VARCHAR(50)
);

-- 2. Вставляем данные (DML)
INSERT INTO developers (name, tech_stack) 
VALUES ('Иван', 'NestJS / TypeScript'), ('Мария', 'Go / PostgreSQL');

-- 3. Читаем данные (DML)
SELECT * FROM developers WHERE tech_stack LIKE '%NestJS%';
```

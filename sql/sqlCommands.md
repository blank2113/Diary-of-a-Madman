# 📖 Полный интерактивный справочник по командам SQL

Этот справочник спроектирован так, чтобы даже человек с нулевым опытом в базах данных мог понять логику языка SQL. Все команды разбиты на четыре канонические группы (DDL, DML, TCL, DCL), снабжены жизненными примерами и комментариями.

## 🏗️ Группа 1: DDL (Data Definition Language) — Управление структурой

Эти команды создают «каркас» (таблицы, схемы, связи), в который потом будут складываться данные. Представьте это как проектирование пустых комнат в доме.

### 1. CREATE TABLE — Создание таблицы
Создает новую пустую таблицу со строгим указанием типов данных для каждой колонки.

```sql
CREATE TABLE users (
    id SERIAL PRIMARY KEY,           -- Уникальный ID, который увеличивается сам (1, 2, 3...)
    username VARCHAR(50) NOT NULL,   -- Строка до 50 символов, пустое значение запрещено
    email VARCHAR(100) UNIQUE,       -- Строка до 100 символов, значения не могут повторяться
    balance NUMERIC(10, 2) DEFAULT 0,-- Число с плавающей точкой (всего 10 цифр, 2 после запятой)
    created_at TIMESTAMP DEFAULT NOW()-- Дата и время, по умолчанию ставится текущий момент
);
```

### 2. ALTER TABLE — Изменение структуры таблицы
Используется, если таблица уже создана, но вам нужно добавить, удалить или изменить колонку без потери существующих данных.

```sql
-- Добавляем новую колонку для хранения номера телефона
ALTER TABLE users ADD COLUMN phone VARCHAR(20);

-- Удаляем колонку balance (осторожно, данные внутри колонки сотрутся!)
ALTER TABLE users DROP COLUMN balance;
```

### 3. DROP TABLE — Полное удаление таблицы
Безвозвратно уничтожает таблицу вместе со всей её структурой и всеми строками, которые в ней лежали.

```sql
DROP TABLE users;
```

### 4. TRUNCATE TABLE — Быстрая очистка таблицы
Удаляет абсолютно все строки из таблицы, но оставляет саму структуру (колонки) нетронутой. Работает в разы быстрее, чем DELETE, так как не пишет логи на каждую удаляемую строчку.

```sql
TRUNCATE TABLE users;
```


## ✍️ Группа 2: DML (Data Manipulation Language) — Манипуляция данными

Самая популярная группа команд. Работает непосредственно со строками внутри созданных таблиц: создает, читает, обновляет и удаляет их (концепция CRUD).

### 1. INSERT INTO — Добавление новых строк
Вставляет новые записи в таблицу. Можно передавать как одну строку, так и список из нескольких строк через запятую.

```sql
-- Вставляем одного пользователя
INSERT INTO users (username, email, phone) 
VALUES ('alex_dev', 'alex@mail.com', '+998901234567');

-- Вставляем сразу нескольких пользователей одним запросом
INSERT INTO users (username, email, phone) 
VALUES 
    ('johndoe', 'john@gmail.com', '+123456789'),
    ('marry_me', 'mary@yandex.ru', NULL); -- NULL означает отсутствие данных (пустоту)
```

### 2. SELECT — Чтение и выборка данных
Основная команда для поиска и фильтрации информации. Имеет огромное количество модификаторов.

Базовый выбор и фильтрация (WHERE):
```sql
-- Выбрать абсолютно все колонки и все строки из таблицы
SELECT * FROM users;

-- Выбрать только имена и телефоны пользователей, у которых задан email
SELECT username, phone 
FROM users 
WHERE email IS NOT NULL;
```

Сортировка (ORDER BY) и лимиты (LIMIT, OFFSET):
```sql
-- Показать топ-3 пользователей, отсортированных по дате регистрации от новых к старым
SELECT username, created_at 
FROM users 
ORDER BY created_at DESC 
LIMIT 3;

-- Пагинация: пропустить первые 10 строк и взять следующие 5
SELECT * FROM users 
LIMIT 5 OFFSET 10;
```

Агрегация и группировка (GROUP BY, HAVING):

```sql
-- Посчитать, сколько пользователей зарегистрировалось в каждый конкретный день
SELECT created_at::DATE AS reg_date, COUNT(*) AS total_users
FROM users
GROUP BY created_at::DATE
HAVING COUNT(*) > 5; -- Оставить только те дни, где регистраций было больше 5
```

### 3. UPDATE — Обновление существующих данных
Модифицирует значения в уже созданных строках.

> ⚠️ ВНИМАНИЕ: Всегда пишите условие WHERE. Если запустить команду UPDATE users SET phone = '123'; без WHERE, телефон поменяется у всех миллионов пользователей в базе данных!

```sql
-- Меняем телефон конкретному пользователю по его ID
UPDATE users 
SET phone = '+998997777777' 
WHERE id = 1;
```

### 4. DELETE — Удаление строк
Удаляет записи из таблицы на основе условий фильтрации.

```sql
-- Удалить пользователя с ником 'johndoe'
DELETE FROM users 
WHERE username = 'johndoe';

-- Удалить всех, кто зарегистрировался раньше 2025 года
DELETE FROM users 
WHERE created_at < '2025-01-01';
```

## 🤝 Группа 3: Область связей — JOIN (Объединение таблиц)
Поскольку данные в реляционных базах разбиты по разным таблицам, операторы JOIN позволяют склеивать их в один понятный отчет на лету.

Представим вторую таблицу orders (заказы), где есть колонка user_id, связывающая заказ с пользователем.

### 1. INNER JOIN — Только строгие совпадения
Возвращает строки только тогда, когда для пользователя из левой таблицы нашелся хотя бы один заказ в правой.

```sql
SELECT users.username, orders.order_date, orders.amount
FROM users
INNER JOIN orders ON users.id = orders.user_id;
```

### 2. LEFT JOIN — Все левые + совпадения справа
Возвращает всех пользователей без исключения. Если у пользователя есть заказы, они подтянут свои данные. Если заказов нет — в колонках заказа будет написано NULL.

```sql
SELECT users.username, orders.amount
FROM users
LEFT JOIN orders ON users.id = orders.user_id;
```

## 🔒 Группа 4: TCL (Transaction Control Language) — Управление транзакциями
Транзакции объединяют пачку команд в единый безопасный блок. Либо выполняются все команды внутри блока, либо не выполняется ни одна.

Классический пример — перевод денег с одного банковского счета на другой. Нельзя допустить, чтобы с одного счета деньги списались, а на второй не зачислились из-за сбоя сервера.

```sql
-- 1. Открываем безопасный блок
BEGIN;

-- 2. Списываем 500 рублей у Айбека
UPDATE wallets SET balance = balance - 500 WHERE user_id = 7;

-- 3. Зачисляем 500 рублей Сардору
UPDATE wallets SET balance = balance + 500 WHERE user_id = 9;

-- 4. Если на этом этапе сервер упал или база выдала ошибку, мы пишем:
-- ROLLBACK; -- База вернет балансы в исходное состояние, как до команды BEGIN

-- 5. Если всё прошло успешно, фиксируем изменения намертво на жесткий диск:
COMMIT;
```

## 🔑 Группа 5: DCL (Data Control Language) — Доступы и безопасность
Команды для администраторов баз данных. Определяют, какому программисту или какому микросервису к каким таблицам разрешено прикасаться.

### 1. GRANT — Выдача прав
```sql
-- Разрешить микросервису 'nestjs_app' только читать (SELECT) данные из таблицы старых логов
GRANT SELECT ON public.system_logs TO nestjs_app;

-- Дать полные права (чтение, запись, удаление) на таблицу пользователей
GRANT ALL PRIVILEGES ON TABLE users TO senior_admin;
```

### 2. REVOKE — Отзыв прав
```sql
-- Забрать обратно право на удаление данных у аккаунта джуниор-разработчика
REVOKE DELETE ON TABLE users FROM junior_dev;
```

## 💡 Шпаргалка для новичка: Шорткат по терминам
  * `WHERE` — фильтр для обычных строк.

  * `HAVING` — фильтр для сгруппированных данных (после GROUP BY).

  * `AS` — создание временного красивого псевдонима (алиаса) для колонки или таблицы (SELECT username AS name).

  * `IN` — проверка на вхождение в список (WHERE id IN (1, 5, 9, 12)).

  * `LIKE` — поиск по текстовому шаблону. Знак % означает любое количество любых символов (`WHERE` username `LIKE` 'alex%' найдет и alex_dev, и alexander).
